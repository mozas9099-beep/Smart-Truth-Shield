# درع الحقيقة الذكي (Smart Truth Shield)

نظام استباقي مدعوم بالذكاء الاصطناعي لكشف الاحتيال الإلكتروني وانتحال الهوية البصرية قبل وقوع الضحية.

## المشكلة
- انتشار الروابط الخبيثة داخل لقطات الشاشة في تطبيقات المحادثة لتجاوز فلاتر الروابط النصية.
- انتحال شعارات البنوك والجهات الحكومية بدقة عالية يصعب على المستخدم العادي تمييزها.
- ظهور نطاقات حديثة الإنشاء قبل ساعات من الهجوم لا تلحق عليها قوائم الحظر التقليدية.
- استغلال الهندسة الاجتماعية ونبرة الاستعجال وطلب رموز التحقق لدفع الضحية لاتخاذ قرار متسرع.

## الحل
منصة فحص استباقية تجمع بين:
- **الرؤية الحاسوبية:** قراءة لقطات الشاشة واستخراج الروابط المخفية ورصد انتحال الشعارات.
- **فحص النطاقات:** التحقق من عمر النطاق وتاريخ تسجيله لكشف النطاقات الحديثة أو المشبوهة.
- **تحليل النبرة والقرار:** رصد أساليب الاستعجال وطلب البيانات السرية، وإصدار نسبة خطورة وتوصية واضحة للمستخدم.

## الخيارات التقنية
- **الذكاء الاصطناعي والرؤية الحاسوبية:** OpenAI GPT-4o-mini لتحليل الصور والنصوص وكشف الهندسة الاجتماعية.
- **فحص النطاقات:** مكتبة `python-whois` لمعرفة تاريخ إنشاء النطاق وعمره.
- **واجهة النموذج الأولي (MVP):** لغة Python مع مكتبة Streamlit لعرض واجهة تفاعلية بسيطة.

## طريقة التشغيل
1. تثبيت المكتبات المطلوبة: `pip install -r requirements.txt`
2. تشغيل الواجهة:`streamlit run app.py`
